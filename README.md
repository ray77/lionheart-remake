# ▶ Play Lionheart in your browser

**This fork adds a browser version of Lionheart Remake** — the full game, compiled
ahead of time from Java to JavaScript with [TeaVM](https://teavm.org/). No plugin,
no JVM, no emulator: the Amiga classic runs at 60 fps with its logic at the
original 50 Hz, Atari sc68 chip music played through WebAssembly, sound effects,
six languages and a score system, straight in the page.

- **Play it now:** [arcade4ever.net](https://arcade4ever.net/games/lionheart/index.html) (free, with an online leaderboard on the site)
- **Download a release:** [lionheart-web.zip](https://github.com/ray77/lionheart-remake/releases) — unpack, serve, play
- **How the port works:** [`web/README.md`](web/README.md) — TeaVM pitfalls, the new
  `lionengine-core-web` backend, build instructions
- **Engine side:** [ray77/lionengine, branch `web`](https://github.com/ray77/lionengine/tree/web)

*Keywords for fellow searchers: Lionheart Amiga remake browser, Java game in the
browser, TeaVM game port, LionEngine WebAssembly, play Lionheart online.*
